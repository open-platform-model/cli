# Tasks: adopt-draft-first-release

One PR for sections 1 to 4 (branch `tags/draft-first-release`), titled `ci(release): cut releases as drafts and add release branches`. The repo squash-merges with the PR title as the commit title, so the title MUST keep a hidden type (`ci`) and the squash body MUST carry no releasable conventional line; merging then cuts no release by itself. Section 5 runs after the first real release and lands as its own small PR. Workers never merge, never tag, never create, edit or delete a GitHub Release, never create a release branch, and never touch rulesets or org settings. Items marked **SUPERVISOR** or **OWNER** are not worker tasks.

Environment for every Go/CUE command, exported on two lines:

```bash
export CUE_REGISTRY='opmodel.dev=ghcr.io/open-platform-model,testing.opmodel.dev=ghcr.io/open-platform-model,registry.cue.works'
export OPM_REGISTRY="$CUE_REGISTRY"
```

`task test` includes `task test:integration`, which needs a live kind cluster; when none is available, run `task test:unit` and `task test:e2e` (with `env -u OPM_CONFIG`) and report integration as skipped instead of starting a cluster unasked.
