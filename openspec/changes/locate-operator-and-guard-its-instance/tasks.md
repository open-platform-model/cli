# Tasks: locate-operator-and-guard-its-instance

Section 1 checks the gate and names the operator's fixed coordinates and its recognition signals without changing behaviour; section 2 moves the running-operator check onto its instance record and the fixed names; section 3 adds the finalizer guard to `opm instance delete` of an instance that deploys the operator. Cluster e2e is not part of any gate here: the local kind cluster has no internet egress, so unit tests on the fake dynamic client are the bar, and the PR says so.
