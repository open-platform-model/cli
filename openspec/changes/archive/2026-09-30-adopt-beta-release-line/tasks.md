# Tasks: adopt-beta-release-line

Three PRs (design.md D3). This change's deliverable is a release cut, so pushing and opening PRs are tasks here (the tasks-rule exception for release work). Workers never merge anything, never run root workspace tasks, never tag or publish. Items marked **SUPERVISOR** are done by the supervisor; items marked **SUPERVISOR PATCH** consume a patch file the supervisor hands over (`git apply <patch>` in the worktree, then read the diff). The supervisor writes every squash message at merge time (never GitHub's default commit list) and checks it with `check-merge-msg.js`.

| PR | Branch | Sections | Squash commit (subject) | Carrier | Merge gate | Expected release PR |
| --- | --- | --- | --- | --- | --- | --- |
| PR-A | `beta/adopt-beta-release-line` | 1 | `fix(inventory): compare only MAJOR.MINOR in the operator ceiling` | no, NO footer | none; merge before PR-B | opens `chore(main): release 1.0.0-alpha.28`: DO NOT MERGE it; it stays open, only the supervisor merges it at G4 after PR-B retitles it |
| PR-C | `beta/cli-fixture-pins` | 6 | `test(fixtures): pin the dev platform and examples to the beta line` | no, NO footer | G3; before PR-B preferred | none (hidden type) |
| PR-B | `beta/adopt-beta-release-line` | 2 to 5, 7 | `fix(deps): move the cli to the beta line on library v1.0.0-beta.1` | YES, footer `Release-As: 1.0.0-beta.1` | G2 + G3, PR-A merged | `chore(main): release 1.0.0-beta.1` (the alpha.28 PR retitled) |

Environment for every Go/CUE command, exported on two lines:

```bash
export CUE_REGISTRY='opmodel.dev=ghcr.io/open-platform-model,testing.opmodel.dev=ghcr.io/open-platform-model,registry.cue.works'
export OPM_REGISTRY="$CUE_REGISTRY"
```

Run the e2e suite with `env -u OPM_CONFIG`. `task test:integration` needs a live kind cluster; when none is available, run `task test:unit` and `task test:e2e` and report integration as skipped under deviations instead of starting a cluster unasked.
