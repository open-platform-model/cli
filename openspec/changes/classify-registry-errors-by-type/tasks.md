Section 1 is the spike: on the released library v1.0.0-beta.4 and today's text probes, table tests pin what each site answers for every failure form, and the rows design.md could not measure in advance (the blob 404, the compat 401/503 rows, the unversioned `cannot find module providing package` forms) are written into design.md as measured.
