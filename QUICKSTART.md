# Quickstart

The OPM quickstart is a page of the documentation site: <https://opmodel.dev/docs/start/quickstart/>. It creates a module from a template and renders it, then deploys a published module to a local kind cluster.

This repo keeps no second copy of it. What a quickstart needs from this repo is here:

- To install `opm`, see [Install the CLI](docs/site/start/install-the-cli.md)
- To build and test `opm` from this checkout, see "Build And Dev Commands" in [`AGENTS.md`](AGENTS.md)
- For the commands and how they fit together, see [`README.md`](README.md)
