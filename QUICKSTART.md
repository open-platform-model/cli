# Quickstart

The Open Platform Model (OPM) quickstart is one page, kept in the `opm` repo and published on the documentation site: [Quickstart](https://github.com/open-platform-model/opm/blob/main/docs/site/start/quickstart.md). It creates a module from a template and renders it, then deploys a published module to a local kind cluster.

What that page needs from this repo is here:

- To install `opm`, see [Install the CLI](docs/site/start/install-the-cli.md)
- To build and test `opm` from this checkout, see "Build And Dev Commands" in [`AGENTS.md`](AGENTS.md)
- For the commands and how they fit together, see [`README.md`](README.md)
